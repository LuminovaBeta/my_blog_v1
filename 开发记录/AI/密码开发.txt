推荐方案

  1. 密码使用哈希存储
      - 使用 Django 的 make_password() 和 check_password()。
      - 将字段长度从 32 调整为 128。
      - 迁移时把现有明文密码转换为哈希值。

  2. 增加文章解锁页面
      - 受保护文章不直接渲染正文。
      - 显示标题、锁定提示和密码输入框。
      - 密码正确后才能返回完整文章内容。

  3. 使用 Session 记录解锁状态
      - 解锁后写入类似：

        request.session[f'article_unlocked_{article.nid}'] = True

      - 同一浏览器会话内不用反复输入。
      - 可增加“重新锁定”功能。

  4. 后台不再回显原密码
      - 编辑时只显示“已设置访问密码”。
      - 提供三个明确操作：
          - 保持原密码
          - 设置新密码
          - 移除密码

      - 避免把真实密码放进 HTML。

  5. 增加尝试限制
      - 连续输入错误 5 次后暂时限制。
      - 使用 Session 记录次数即可，第一版不需要复杂的 Redis 限流。

  6. 统一权限判断
      - 管理员可以直接访问。
      - 普通访客必须解锁。
      - 评论、收藏等功能也应检查文章是否已解锁，避免绕过正文页面。

  建议第一版先完成：哈希存储、密码验证页、Session 解锁、后台不回显密码。
