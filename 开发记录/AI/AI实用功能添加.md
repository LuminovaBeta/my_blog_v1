 ## 最值得添加的功能

  ### 1. 草稿、预览与定时发布(已完成)

  目前文章基本只有“未发布/已发布”。可以继续增加：

  - 自动保存草稿
  - 发布前预览
  - 定时发布
  - 文章撤回
  - 历史版本与恢复
  - 离开编辑器时提示未保存内容

  这是最能提升日常写作体验的一组功能。

  ### 2. 完整的文章访问控制

  你已经有文章密码字段，但尚未形成完整功能。可以做成：

  - 公开文章
  - 登录后可见
  - 密码访问
  - 私密文章

  文章密码不要明文展示或保存，应该使用哈希校验。

  ### 3. 更强的搜索系统

  现在主要按标题匹配，可以扩展为：

  - 同时搜索标题、摘要、正文和标签
  - 搜索关键词高亮
  - 搜索历史
  - 按分类、时间、字数、热度组合筛选
  - 没有结果时推荐相似文章

  文章数量不多时用 Django/MySQL 即可，内容规模变大后再考虑 Meilisearch 或 Elasticsearch。

  ### 4. 专栏与系列文章

  相比单纯标签，专栏更适合技术博客：

  - 一篇文章属于某个系列
  - 系列内设置章节顺序
  - 上一篇/下一篇
  - 阅读进度
  - 系列目录
  - 系列完结状态

  例如“Django 博客开发记录”“无人机学习笔记”等。

  ### 5. 评论系统增强

  现有树形评论基础上可以增加：

  - 评论审核
  - @回复通知
  - 删除后的占位展示
  - 评论编辑
  - 举报与垃圾评论过滤
  - 用户只能给同一评论点赞一次
  - 管理员置顶或精选评论
  - 邮件通知作者和被回复用户

  建议限制评论嵌套层级，界面仍可平铺显示回复关系，避免层级太深。

  ### 6. 用户通知中心

  把用户互动串起来：

  - 评论被回复
  - 文章被收藏
  - 评论被点赞
  - 管理员公告
  - 未读数量
  - 一键全部已读

  初期用站内通知即可，邮件通知作为用户可选设置。

  ## 对博客传播最有帮助的功能

  ### 7. SEO 与内容订阅

  建议增加：

  - 每篇文章独立的 SEO 标题和描述
  - Open Graph 分享卡片
  - 自动生成 sitemap.xml
  - robots.txt
  - RSS/Atom 订阅
  - 规范链接 canonical URL
  - 文章永久链接或 slug
  - 结构化数据
  - 自动生成文章目录

  这类功能不显眼，但非常适合长期积累搜索流量。

  ### 8. 文章阅读体验

  可以做：

  - 阅读进度条
  - 自动生成目录并高亮当前位置
  - 代码一键复制
  - 图片点击放大
  - 深色代码主题
  - 字号和行距切换
  - 上一篇/下一篇
  - 相关文章推荐
  - 预计阅读时间
  - 最后更新时间提示

  你已经有字数统计和主题切换，实现这些的成本比较低。

  ### 9. 数据统计面板

  后台增加一个简单的数据看板：

  - 每日访问量、访客数
  - 热门文章
  - 搜索关键词
  - 收藏、点赞、评论趋势
  - 流量来源
  - 设备与屏幕尺寸
  - 最近发布表现

  注意过滤站长自己的访问以及机器人流量。初期不必追求复杂分析，先保证统计口径准确。

  ## 可以体现个人特色的功能

  ### 10. 项目作品集

  你的模型中已经有 Project，可以把它发展成独立作品集：

  - 项目介绍与截图
  - GitHub/Gitee 地址
  - 在线演示
  - 技术栈标签
  - 项目状态
  - 关联开发日志
  - 版本更新记录

  对个人博客来说，这通常比“新闻频道”更有价值。

  ### 11. 短内容动态

  现有“心情”页面可以定位为轻量动态：

  - 短文字和图片
  - 关联地点或心情
  - 时间线
  - 仅自己可见/公开
  - 年度回顾
  - 动态评论

  这样可以承载不值得写成长文章的内容，但建议等文章主流程稳定后再做。

  ### 12. 友链和网站导航申请

  你已经有导航模型，可以完善为：

  - 用户提交友链
  - 管理员审核
  - 网站图标自动获取
  - 链接存活检测
  - 失效链接提醒
  - 分类和排序
  - 防止恶意 URL、内网 URL 和脚本协议



### 第一阶段：完善内容体验

  1. 友情链接管理（暂不加）
      - 后台增删改查
      - 首页真实展示
      - 后续增加申请与审核

  2. 文章目录
      - 根据 Markdown 标题自动生成
      - 阅读时高亮当前位置
      - 长文章体验会明显改善

  3. 相关文章推荐
      - 根据标签、分类推荐 3～5 篇文章
      - 优先推荐同标签内容

  4. 上一篇 / 下一篇
      - 放在文章正文底部
      - 帮助用户继续浏览

  5. 文章搜索优化
      - 支持标题、摘要、正文、标签联合搜索
      - 搜索关键词高亮
      - 增加分类和发布时间筛选

  ### 第二阶段：完善创作流程

  1. 草稿自动保存
      - 定时保存
      - 显示“已保存/保存中/保存失败”
      - 离开页面前提示未保存内容

  2. 文章定时发布
      - 设置发布时间
      - 到期后自动公开

  3. 文章版本历史
      - 保存历史版本
      - 查看修改时间和差异
      - 支持恢复旧版本

  4. 编辑器图片管理
      - 上传图片
      - 查看文章使用过的图片
      - 删除未被引用的图片

  5. SEO 设置
      - 自定义页面标题、描述和关键词
      - 自动生成 sitemap.xml
      - 自动生成 RSS

  ### 第三阶段：完善互动能力

  1. 评论回复
      - 后台直接回复
      - 回复后在原评论下展示
      - 支持删除、隐藏和审核

  2. 评论通知
      - 新评论提醒作者
      - 评论被回复时提醒用户
      - 初期可以只做站内未读标记

  3. 点赞功能完善
      - 防止同一用户重复点赞
      - 未登录用户可按浏览器或 IP 限制

  4. 收藏夹
      - 支持创建多个收藏夹
      - 对收藏文章进行分类

  5. 访客留言板
      - 与文章评论分开
      - 更适合博客访客交流

  ### 第四阶段：数据统计

  1. 访问趋势
      - 最近 7 天、30 天阅读量
      - 使用简单折线图展示

  2. 热门内容分析
      - 阅读量、评论量、收藏量排行
      - 支持按时间范围统计

  3. 文章数据详情
      - 每篇文章的访问趋势
      - 阅读来源、设备类型和浏览器
      - 不建议一开始收集过多个人信息

  4. 搜索词统计
      - 用户搜索了什么
      - 哪些关键词没有搜索结果

  ### 第五阶段：管理与安全

  1. 评论审核与敏感词过滤
  2. 登录失败次数限制
  3. 文章和评论操作日志
  4. 数据库及媒体文件备份
  5. 图片格式和大小校验
  6. 文章访问密码校验完善
  7. 后台分页、筛选和批量操作

  我建议你接下来的开发顺序是：

  1. 友情链接真实化
  2. 自动保存状态完善
  3. 相关文章和上一篇/下一篇
  4. 评论回复与通知
  5. 文章版本历史
  6. 访问趋势统计
  7. SEO、RSS 和站点地图

  其中，相关文章、上下篇导航、评论回复和 SEO投入较小，但对博客完整度提升最明显
